# 小红书发布稿

标题：我给电脑养了个会说话的小可爱

本来只想做个桌宠，后来又给她加上了对话、语音和任务进度。现在，她能回应桌面上的一些小互动了。

她叫 Debby。摸摸头会回应，指数涨跌会变心情。今天累了，也可以直接点「今天有点累」，和她聊两句。

这次把第一次聊天也重新做了：桌面一点进对话，先选一句，不知道怎么问也能开口；回答后还有接话选项。自己的模型 Key 配好后，就能用中文对话和语音。

我还想把她做成一个方便接入的虚拟人壳子，让不同 Agent 都能借她展示进度、说话和庆祝。视频最后就是一个本机 Harness 通过 MCP 控制她的演示。

目前 Windows 优先、个人非商用开发中。画面为实际产品录制；行情为演示数据，不是实时盘面或投资建议。对话 / 语音需要自己配置 BYOK，按自己的供应商额度使用。

你希望她下一步学会什么：番茄钟陪伴、每天一句问候，还是完成任务后给你庆祝？

#桌宠 #桌面美化 #AI陪伴 #开源项目 #独立开发 #Debby

署名：角色 Zome，作者 Yorshka；素材来自 Shiny / Mate-Engine。个人非商用演示。旁白与对话语音由阿里云 TTS 合成，实际对话使用配置的 Qwen 模型；配乐为原创合成音。

项目地址： https://github.com/CheaSim/Debby

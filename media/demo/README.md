# Debby 竖屏演示

主片、封面、字幕和发布文案放在此目录。参数见 `validation.json`，复现方式见 [演示说明](../../docs/community-demo.md)。

本目录影像含第三方角色，不能将根目录的 MIT 代码许可证理解为第三方美术素材的再授权。角色 Zome：Yorshka；素材来源 Shiny / Mate-Engine。演示为个人非商用预览，角色使用遵循 [上游固定版本许可](https://github.com/shinyflvre/Mate-Engine/blob/2c5ea6b8f4cf5e1773a0816b46d9267cda5174d4/LICENSE.md)。VRM、贴图和独立角色素材不在此目录分发。

实际应用录制；行情为受控演示数据。旁白和对话声音由阿里云 TTS 合成，背景音乐为脚本原创合成音、没有外部采样。没有摄像头或麦克风录制素材。

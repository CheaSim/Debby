# Debby 社区演示与第一次对话

这版面向小红书 / 抖音的竖屏观看：先看到角色回应，再理解怎么开口，最后看到 Agent 接入。主片约 40 秒，使用实际 Electron 产品画面、真实阿里云对话和语音。素材与录制脚本一起保留，方便其他开发者换角色、换后端后重新制作。

## 新用户动线

`看到桌宠 →「点这里，问我一句」→ 点击对话 → 选一句 / 自己输入 → 首次 BYOK 与传输确认 → 问题保留 → 主动发送 → 流式台词 / 可选朗读 → 接着聊`

桌面保持「对话 / 面板 / 更多」三个入口。首次提示依附既有对话按钮，不增加常驻按钮，点击后在本地记住已读。不弹阻塞欢迎页。

对话一开始给出「今天大盘怎么样？」「今天有点累」「你能帮我做什么？」三个具体话题，不要求用户先理解模型或 Agent。输入框始终可见；没有配置时也能先写一句。选择问题只会打开必要配置，不偷偷发送、不自动开启设备。完成配置或授权后保留原问题，由用户发送。

回答后按当前话题提供下一步：行情可看自选、查时间来源，陪伴可继续倾诉、要一个小建议。建议由 `src/shared/dialogue-guidance.ts` 直接生成，不增加模型调用；其他 Agent 后端可复用或替换。失败保留草稿，允许重试。按 Enter 发送，Shift + Enter 换行。

文字模型可用时优先文字入口；只有通义已配置时可进入陪伴入口。语音会话另行确认；麦克风和摄像头均由用户主动开启。选择推荐问题不会绕过 BYOK 或云端传输确认。

## 主片结构

| 时间（约） | 画面与目的 |
| --- | --- |
| 0–3 秒 | 近景角色与摸头动作；「电脑里，住进了一个小可爱」 |
| 3–7 秒 | 摸头回应、爱心眼与歪头，建立陪伴感 |
| 7–13 秒 | 演示指数上涨 / 下跌，心情和提示同步改变 |
| 13–21 秒 | 桌面点对话、推荐问题、传输确认、问题保留，说明第一次怎么开口 |
| 21–29 秒 | 真实 Qwen 模型回答、阿里云音频流、嘴型；保留实际等待过程 |
| 29–30 秒 | 接话选项，说明聊天不是一次性入口 |
| 30–35 秒 | 本机 Demo Harness 实际经 MCP 发送任务与动作，展示进度和庆祝 |
| 35–40 秒 | 名称、仓库地址、评论话题与角色署名 |

## 录制与复现

先运行 `npm.cmd run build`。需要本地已安装 FFmpeg / FFprobe，以及忽略的 `.env` 中自己的 `DEBBY_QWEN_*`。录制会真实调用所配置的对话和 TTS，消耗该账号额度；不会打开麦克风或摄像头。

```powershell
node scripts/capture-community-demo.mjs
node scripts/render-community-demo.mjs
```

录制使用隔离临时用户目录，不读取个人聊天或自选。逐帧 PNG 截屏按实际时间编码，再合成 1080p 视频，避免测试录屏的低码率损伤细节。原始帧、原声和中间文件保留在被 Git 忽略的 `work/community-demo/`；最终公开素材在 `media/demo/`。主进程处理密钥，脚本不输出原始云端响应或临时签名地址。背景颜色及角色摆位为录制构图调整，交互与渲染均来自实际产品。

行情是受控演示数据，画面保留「演示数据 / 非实盘」；不表示实时行情、收益或投资建议。MCP 片段来自脚本内的实际测试客户端，不冒充已连接的 Codex / Claude Code 会话。对话片段使用实际配置的 Qwen 文字模型和阿里云 TTS，不是原生 Omni 或持续双向通话。

模型是 Mate-Engine 的 Zome，角色作者 Yorshka，上游素材署名 Shiny；参见 [上游固定版本许可](https://github.com/shinyflvre/Mate-Engine/blob/2c5ea6b8f4cf5e1773a0816b46d9267cda5174d4/LICENSE.md) 与本地 `src/renderer/public/models/mate-engine/SOURCE.md`。演示素材为个人非商用预览，不能把模型资源当作本项目 MIT 代码重新授权；仓库不提交 VRM 或贴图原文件。

## 核验

以 FFprobe 核验最终尺寸、时长、帧率和音轨，逐镜抽帧检查中文、角色、字幕和按钮，检查成片解码无错误与音频非静音。真实回答原文、收到的音频分块数、成片参数记录在 `validation.json`。应用还通过单元测试、桌面交互、问答动线、语音权限和流式朗读回归。

# FinPet 产品路线与交付标准

定位：会跟随市场变换心情的 3D 金融桌面伙伴。以角色表现、真实数据边界和桌面可靠性建立辨识度，不做收益承诺，不用交易次数或亏盈决定用户好感度。

## 竞品参考

调研日期：2026-10-07。以下以各项目官方介绍为依据，不将竞品自报性能作为本项目实测值。

| 项目 | 参考能力 | 本项目取舍 |
| --- | --- | --- |
| [Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/) | 窗口边缘坐姿、跳跃、鼠标互动、闹钟 | 先把互动反馈做好，窗口吸附后续处理多屏与 DPI |
| [VPet](https://github.com/LorisYounger/VPet) | 摸头、提起、养成、丰富动画与创意工坊 | 跟进状态化陪伴；成长不奖励频繁交易 |
| [Mate-Engine](https://github.com/shinyflvre/Mate-Engine) | VRM、触摸区域、拖拽动作、坐姿、音乐互动 | 参考角色与动作体验；当前主窗口不是嵌入完整 Unity 引擎 |
| [AIRI](https://github.com/moeru-ai/airi) | 实时语音、Live2D/VRM 交互 | 可选语音后置，确定性金融规则不交给语言模型 |
| [Bongo Cat](https://store.steampowered.com/app/3419430/Bongo_Cat/) | 即时反馈、装饰收集、常驻陪伴 | 少操作也有反馈，优先专注计时，不记录键盘输入内容 |

## 当前完成的一轮

- [x] 角色动作控制器与 Three.js AnimationMixer 混合，互动动作和指数表情分离。
- [x] 待机、招呼、摸头、提起、落地、开心、安慰、提醒八类动作。
- [x] 基于模型射线命中的头部/身体触摸；拖拽取消后可恢复，不与旋转模式混用。
- [x] 指数心情退出阈值与动作冷却，离线状态立即生效。
- [x] 独立的五场景演示、播放/暂停/重播/退出，实盘数据与提醒配置不被合成数据覆盖。
- [x] 带源日期和来源的行情/收盘复盘快照、PNG 导出、文字复制。
- [x] 本地开发正常运行；标准安装包流程拒绝包含受限 Zome 模型。

这轮动画关键帧由 FinPet 独立编写，使用 Three.js 的现有混合器；不宣称继承 Mate-Engine 的全部动作库或窗口交互能力。当前角色仍是上游 Zome 本地预览资产，不是原创角色。

## 演示脚本

用真实窗口录制 60 秒：角色出现与摸头回应、拖动提起与落地、切换涨跌表情、演示提醒、断线状态、收盘复盘及图片导出。涉及合成行情的画面必须保留“演示数据 · 非实盘”，宣传不能把演示价格包装成实盘。

自动序列每场 12 秒，播放到收盘后停止；可暂停、重播、手动切场。演示退出后继续显示原行情。真实系统提醒在后台仍然有效，演示本身不生成系统通知。

## 下一轮

1. 角色发行权与品牌：审查代码、模型、动作、语音各自许可；取得授权或制作原创 VRM。
2. 市场陪伴：交易日历、开盘问候、午间休息、收盘提醒与长期快照保存。
3. 日常留存：专注计时、休息提醒、动作频率设置和轻量装饰。
4. 个性化：VRM 导入、授权动作包、窗口坐姿；再评估可选语音。

## 发布验收

- [ ] 无开发环境的干净 Windows 账户可以安装、启动、卸载，不要求 Node/npm。
- [ ] 可发行角色与所有保留资源已逐项完成许可审查和署名。
- [ ] 100%/150%/200% 缩放，多屏及负坐标、断网恢复、睡眠唤醒、全屏应用通过。
- [ ] 8 小时持续运行与多轮展开/收起不发生资源持续增长或交互失效。
- [ ] 在明确硬件上记录待机/互动/面板状态 CPU、GPU、内存和帧率，不凭感觉宣传低占用。
- [ ] 提供中文上手说明、隐私与数据源说明、架构图、真实录屏与依赖署名。

## 本轮验证记录

2026-10-07，本机 Windows，Electron 渲染缩放 200%。

- 类型检查、39 个领域测试、生产构建通过。
- Electron 端到端检查真实 VRM 贴图、透明像素、全身/近景、摸头/提起/落地、窗口拖拽与位置持久化、独立旋转、穿透开关、侧边收起按钮。
- 场景演示在展开和紧凑窗口均可操作；验证实盘配置与后台行情不被覆盖，复盘弹窗可用 Escape 关闭。
- 复盘实际导出 1000 x 728 PNG 并检查格式、尺寸与排版；文字复制通过替身检查，不在自动化中覆盖用户剪贴板。
- 公开行情实测使用腾讯，指数为上证指数；2026-09-30 16:15 的源行情日期保持不变。真实模式复盘不含演示标记，退出演示后恢复原供应商。
- Windows 原生点击确认摸头回应、演示进入/暂停/退出、复盘打开/关闭和面板展开/收起。此检查发现并修复侧边按钮被透明模型层遮挡的问题。
- 打包资产检查按预期拒绝 Zome，未制作或发布含受限模型的安装包。

剩余验证缺口：其他缩放比例、多屏、睡眠恢复、长时间压力测试与干净系统安装仍待完成。现有 `lint` 脚本没有 ESLint 配置，本轮未将其计为通过。

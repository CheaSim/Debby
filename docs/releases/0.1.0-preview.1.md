# Debby 0.1.0 Preview

2026-11-07 · Windows x64 · 个人非商用预览

[下载预览版](https://github.com/CheaSim/Debby/releases/tag/v0.1.0-preview.1) · [15 秒真实 MCP 演示](../../media/demo/debby-agent-15s.mp4)

安装 `.exe`，或解压 `.zip` 后打开 `Debby.exe`；无需 Node.js、Unity 或 Python。首次默认全身鲸鱼娘，保留完整双手、衣裙与脚部。程序会记住之后保存的角色选择。

「更多 → 体验 Debby · 不用 Key」在本地演示工作、等待你、完成庆祝，可直接在气泡继续或结束。「对话」直接打开输入框，未配置时再引导自己的 BYOK。「Agent 接入」可复制 JSON / Codex TOML，连接程序和运行时均随安装包提供。用户仍需在自己的 Agent 客户端合并配置并重新连接。

## 验证

- TypeScript 检查及 192 项测试通过。
- 对真实打包应用运行隐藏、静音、隔离配置的端到端测试：默认全身角色、原生窗口拖拽、免 Key 演示、快速对话、MCP stdio 握手与七项工具发现、表情切换、舞蹈播放与恢复鲸鱼娘、保存 3D 选择后重启。
- 打包后检查实际 `app.asar` 的模型哈希、嵌入许可、署名与依赖许可；Zome、Haru、Cubism Core、`.env` 和 Agent 令牌均排除。已检查本机已知 Key 没有进入应用或 MCP 包。
- 视频 FFprobe 核验为 15.000 秒、1080×1920、H.264 / AAC、30 fps；完整解码无错误，阿里云温柔旁白解码非静音。任务与行情为明确标记的演示，由真实 MCP 客户端驱动。

复现检查：`npm.cmd run package:win`，然后 `node tests/release.e2e.mjs`。视频复现见 [社区演示](../community-demo.md)。安装器已构建；桌面测试运行的是随包生成的可执行应用，没有向个人 Windows 配置静默安装。

## 资源与边界

代码 MIT；鲸鱼娘美术 CC BY-NC-SA 4.0，署名链与完整条件见 [发行说明](../../RELEASE-NOTICES.md)。鲸鱼娘是 2.5D 分层插画；3D 骨骼舞蹈使用另一具 pixiv VRM 示例身体。MCP 测试使用官方 SDK，不等同于在每一个第三方客户端完成配置验收。MCP 台词本身不触发收费 TTS。聊天和语音需用户自己的服务配置。

预览包未代码签名，Windows 可能显示未知发布者。
